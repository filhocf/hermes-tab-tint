# Changelog

## 0.3.0

Two-level tab groups (#142689): six arrangements (columns-2/3/4, rows-2/3/4) registered in the `layouts` area, applied through the host layout verb with a navigate fallback, weights normalized, and the last applied arrangement restored on boot from plugin storage. Includes the RED suite (25 tests, ARR-01..ARR-07).

## 0.2.0

Light presets and a per-tab text colour: ten colours in both a dark and a light variant, a fourth colour field for text, and every preset contrast-checked (WCAG) against its own background and composer.

## 0.1.0

First publication: per-tab themes for Hermes Desktop — tab chassis, divider lines, chat surface and composer tint, rounded tab tops and a gap between tabs.
